# AI Financial System

This project is an AI-based financial system that includes:

- Fraud Detection using Machine Learning
- Credit Risk Assessment
- Market Prediction using LSTM
- News Sentiment Analysis using NLP

## Technologies Used:
- Python
- Streamlit
- Scikit-learn
- TensorFlow
- NLP (VADER)

## Features:
- Real-time predictions
- Risk classification
- Financial analytics dashboard
